EDMS brand assets. `logo.png` is provided by EDMS; `logo.ico` is a custom
DataBridge-specific mark generated with Pillow (see below) since the
official EDMS mark alone was too abstract to represent what this specific
tool does, and doesn't need to double as an icon for it.

- `logo.png` — the official EDMS "ED" circle mark, resized to 96x96,
  shown at the top of the app window (the in-app header only). Loaded
  automatically by `load_logo_image()` in `edms_databridge.py`; the app
  falls back to a plain text title if this file is ever missing.
- `logo.ico` — a single bold document icon (not the "ED" mark),
  representing the file this tool produces for you. Saved as a
  multi-resolution icon (16/24/32/48/64/128/256px) and used everywhere
  *except* the in-app header: the title bar, taskbar, and the built
  `.exe`'s file icon (via `--icon assets\logo.ico` in `build.bat`/CI).
  Generated by
  [`source/generate_databridge_icon.py`](source/generate_databridge_icon.py) —
  re-run that script (from the repo root) to tweak the design; colors are
  sampled from EDMS's real logo so it stays on-brand.
  An earlier version tried to show JSON braces turning into the document
  via two cards and an arrow, but that much detail became an unreadable
  blob once actually shrunk to 16-32px (the sizes Windows renders this
  icon at) — the single document shape reads clearly at every size.
- `banner.png` — the wide "Emergency Doctors Medical Service" lockup,
  resized to 800x450. Not currently used anywhere (was tried at the top
  of the README, but didn't look good there) - kept in case it's useful
  later.
- `source/` — everything needed to regenerate the above:
  - `edms-icon-source.jpg` / `edms-banner-source.jpg` — the original,
    unedited files EDMS provided (-> `logo.png` / `banner.png`).
  - `generate_databridge_icon.py` — regenerates `logo.ico`.
  - `databridge-icon-generated.png` — the 1024x1024 render that
    `logo.ico` was built from, kept for reference/reuse.

Regenerating `logo.png` or `banner.png` at a different size just needs
Pillow:

```python
from PIL import Image
icon = Image.open("assets/source/edms-icon-source.jpg").convert("RGBA")
icon.resize((96, 96), Image.LANCZOS).save("assets/logo.png")
```
